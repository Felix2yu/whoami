whoami iframe 嵌入实测

这个页面故意跑在另一个端口（python3 -m http.server 9099 -d examples）， 和 http://127.0.0.1:8080 构成跨源嵌入，用来验证真实场景。

1. 默认嵌入：应自动进紧凑版式，JS 回报同源成功，IP 是访客真实地址

2. 335px 窄容器：控件必须一行摆完，不出横向滚动条

3. 只留设备信息，隐藏 IP 行（?hide=ip）— 保留你旧的 IP iframe 时用这个

4. sandbox 不给 allow-scripts：JS 不执行，?detail=1 要显式说明只用了服务端信号

5. 收紧 allow 之外还带 ?embed=0：强制完整版式，验证参数能覆盖自动判定

6. ?detail=1：在结果表下面展开来源、判定分、边界说明与原始证据

宿主监听 whoami:height 消息，按 e.source 匹配 iframe 自动调高度： 页面内容变化（JS 回报到达、窗口 resize）都会重新上报。

另开一个终端验证响应头里只有 frame-ancestors，没有 X-Frame-Options 与 COEP/CORP：

curl -si http://127.0.0.1:8080/ | grep -iE 'x-frame-options|cross-origin|content-security-policy'
